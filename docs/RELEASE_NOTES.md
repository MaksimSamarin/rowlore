# Заметки о релизах

## 2.3.0

- **Rowlore.** Analyzer теперь называется Rowlore. Новый знак в меню и новая иконка вкладки.
- **Боковое меню.** Анализ и администрирование открываются в одной оболочке с меню слева. Шаги «Данные и модель», «Шаблон» и «Запуск» отмечаются по мере готовности. Тема и меню пользователя — внизу меню.
- **Единый вид.** Один набор цветов для обоих экранов, одни цвета статусов, шрифт Manrope с табличными цифрами. Шрифт входит в сборку и не загружается из интернета.
- **Тема как в системе.** Пока тема не выбрана, интерфейс следует настройке системы. Выбранная раньше тёмная тема сохраняется.
- **Обновление.** Данные, настройки `.env` и тома сохраняются. Порядок обновления — в README, раздел «Обновление с Analyzer».

## 2.2.0

- **Язык.** По умолчанию используется английский. Выберите английский или русский в Administration → Settings. От языка зависят интерфейс, встроенные промпты и демо-файлы.
- **CSV и XLSX.** Можно загрузить оба формата. Разделитель и кодировка CSV определяются автоматически.
- **Группы и квоты.** Доступ настраивается по группам. При исчерпании квоты отчёт может перейти на паузу с сохранением готовых строк.
- **Каталог моделей.** Администратор выбирает доступные и основную модели и проверяет подключение к провайдеру.
- **Локальный вход и OIDC.** Пароли сохраняются при обновлении. Для внешнего входа можно подключить OIDC-провайдер.
- **Отчёты.** Можно посмотреть запрос к модели, выгрузить ошибки в Excel, повторно скачать промежуточный файл и удалить выбранные отчёты за один раз.

## 2.0.0

Первый публичный релиз добавил конструктор полей ответа, групповой анализ, потоковый экспорт Excel, предварительный просмотр результатов и обратную связь модели при повторе.

## 1.0.0

Первая версия поддерживала анализ отзывов из Excel, историю отчётов и выгрузку Excel.
